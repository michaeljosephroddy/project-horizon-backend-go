# project-horizon-backend-go

Mood & Sleep Analytics API (Go Backend)

This is a Go (Golang) backend service that provides analytics for user mood and sleep data.
It collects mood and sleep entries, calculates insights, and returns summarised metrics through REST APIs.

## What It Does

Tracks user mood ratings and sleep logs.

Calculates averages, trends, streaks, and tag frequencies.

Compares current data with previous periods.

## Run Locally
go mod tidy
go run main.go
